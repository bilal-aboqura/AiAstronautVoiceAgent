# Contract: Knowledge Entry Schema

**File**: `specs/004-space-knowledge-base/contracts/knowledge-entry.contract.md`  
**Purpose**: Define the canonical JSON file structure and validation contract for curated space facts.

---

## 1. Directory Structure

Curated facts are placed under the root `knowledge/` folder:

```text
knowledge/
├── sun.json
├── planets.json
├── moon.json
├── pluto.json
├── missions.json
├── black-holes.json
├── iss.json
└── index.json       # Auto-generated by build script
```

---

## 2. JSON Schema Definition

Every category file MUST contain a JSON array of `KnowledgeEntry` objects conforming to this JSON Schema (draft-07):

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "KnowledgeCategoryFile",
  "type": "array",
  "items": {
    "type": "object",
    "required": ["id", "category", "title", "content", "source_name", "source_url"],
    "additionalProperties": false,
    "properties": {
      "id": {
        "type": "string",
        "pattern": "^[a-z0-9]+(-[a-z0-9]+)*$",
        "description": "Unique kebab-case identifier."
      },
      "category": {
        "type": "string",
        "enum": ["sun", "planets", "moon", "pluto", "missions", "black-holes", "iss"],
        "description": "Category discriminator matching the file."
      },
      "title": {
        "type": "string",
        "minLength": 3,
        "maxLength": 120,
        "description": "Concise factual title."
      },
      "content": {
        "type": "string",
        "minLength": 20,
        "maxLength": 2000,
        "description": "Verified scientific facts, numbers, and context in Arabic or English."
      },
      "source_name": {
        "type": "string",
        "minLength": 2,
        "maxLength": 80,
        "description": "Authoritative publishing organization (e.g., NASA Science, ESA)."
      },
      "source_url": {
        "type": "string",
        "format": "uri",
        "pattern": "^https://",
        "description": "Verifiable HTTPS URL of the primary scientific reference."
      }
    }
  }
}
```

    "category": "sun",
    "title": "Sun Core Temperature and Nuclear Fusion",
    "content": "تبلغ درجة حرارة مركز الشمس حوالي 15 مليون درجة مئوية (27 مليون فهرنهايت). عند هذه الحرارة والضغط الهائلين، يحدث الاندماج النووي محولاً الهيدروجين إلى هيليوم ومطلقاً طاقة هائلة.",

    "id": "apollo-11-landing",
    "category": "missions",
    "title": "Apollo 11 Moon Landing Milestone",
    "content": "هبطت مركبة أبولو 11 على سطح القمر في منطقة بحر الهدوء يوم 20 يوليو 1969. كان نيل أرمسترونج وباز ألدرين أول رائدي فضاء يمشيان على سطح القمر، وقضيا ساعتين و31 دقيقة خارج المركبة.",
